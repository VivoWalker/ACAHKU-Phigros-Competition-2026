# 通用賽事（實驗版）

標準模式可更換賽名、曲庫、預選課題、加賽曲及視覺素材。它保留目前的預選賽和八人雙淘汰賽規則，決賽使用兩首固定曲目；不需要 ACAHKU 的第三首曲目、Ending Song Video 或侵入／淨化特效。

## 啟動一場獨立賽事

```sh
npm start -- --standard --data-dir ./data-community
```

打開終端列出的主控網址並使用本次配對碼登入。`data-community/` 保存這場賽事的進度、配對碼、備份和上傳影片，已加入 Git 忽略規則。每場比賽請使用不同的 `data-名稱/` 資料夾；同時運行多場時也需要設定不同的 `PORT`。

`--standard` 只決定**空資料夾的初始配置**，不會轉換已有存檔。不加此參數仍使用 ACAHKU 預設；載入舊資料夾時沿用其原有規則。測試時請使用新資料夾，保留現有正式賽事的整個 `data/`。

## 開賽前設定

1. 在 **Event & library** 儲存賽事名稱、日期和主辦方。
2. 在曲庫新增或修改歌曲，填寫曲名、難度、等級、曲繪及預覽音訊的本機路徑。勾選 **Include in regular 6-song draws** 的曲目會進入常規抽曲池。批量替換可使用模板 JSON。
3. 將預留的加賽曲和決賽曲排除在常規抽曲池外。在 **賽事模板** 選擇第一／二輪預選加賽曲、兩首不同的決賽曲，填寫 Logo、主視覺和合作標誌的路徑，再按 **保存標準賽事**。空白圖片欄表示不使用該圖片。
4. 在預選賽的課題設定中，各選擇三首曲目；核對選手名單。兩輪可以使用不同的加賽曲。
5. 在 **中場影片** 上傳或選擇本次比賽的影片。標準模式不會自動使用內建的 Arcaea 預告；影片仍播放一次後返回休息畫面，使用現有全域音量設定。
6. 按 **檢查曲庫與素材** 核對缺失路徑及常規曲庫數量，然後才選擇預選方案並開賽。

八人賽程的 13 場常規雙淘汰賽每場選用兩首，抽選前仍要有六首未使用候選，因此建議至少準備 **30 首不同的常規曲目**，另留加賽餘量。此數量提示不保證任意次數的加賽都能繼續；曲庫不足時需補曲。決賽和預選加賽曲不計入此數量。

選擇預選方案、開始計分或產生對陣／賽事紀錄後，模板和已指定的決賽／預選加賽曲會鎖定。這避免中途換配置改變判定。普通曲庫仍可依既有規則補曲。需要另一套配置時，開新的資料夾；賽事中途保存與恢復請使用 **Export state backup**，不是模板。

## 複用模板

在 **賽事模板 → 匯出模板** 下載 `event-template.json`。它包含賽事資料、曲庫、兩輪預選課題、加賽曲、決賽曲、品牌圖片路徑及中場影片設定。

它不包含選手名單、分數、抽曲／晉級紀錄、配對碼或播放進度。匯入只限開賽前；成功匯入會產生新的賽事 ID。可把 JSON 交給下一場主辦方，在全新標準賽事中匯入，再填寫當次選手名單。

**圖片、音訊和影片的檔案本身不在 JSON 裡。** 將圖片放在 `public/assets/` 下，音訊放在 `public/assets/song-preview/` 下，模板填寫 `assets/...` 相對路徑。另一台電腦需要複製相同路徑的素材。已上傳的影片位於該場資料夾的 `media/`，可複製到新場相同相對路徑，或在新場重新上傳。匯入後再次執行素材檢查。

模板只接受本機素材路徑，不能填外部網址。空白音訊不播放預覽；缺失曲繪會使用既有回退顯示，但播出前應修正缺失素材。自備片段請先做好音量平衡；全域音量控制會統一調整播放增益，不會自動正規化任意新檔案。

## 決賽與相容性

標準決賽依序公布兩首曲目並播放預覽（各 12 秒），接著進入準備、比賽、統計和賽果確認。兩首總分決定勝負，同分仍沿用平均 ACC 及加賽流程；加賽曲也有單獨公布頁面。確認後可以顯示賽事總排名。

**ACAHKU 2026 預設** 保留原本三首制決賽、專屬 PV、錯誤侵入及淨化演出。原有存檔不會自動改為標準模式。開賽前可以透過預設按鈕回到 ACAHKU 配置；標準模板則始終採用兩首制決賽。

此版沒有加入任意人數的雙淘汰樹、自訂計分公式、其他晉級名額或可編排的特效插件。八人雙淘汰、Plan A／B、三首預選課題和既有判分規則仍是共同基礎。

## 驗證

```sh
node --test test/event-templates.test.js
python3 scripts/test-regressions.py --suite browser-smoke --only event-templates-browser
```

瀏覽器測試使用臨時資料，涵蓋模板匯入、手機版、配置鎖定，以及自訂曲目決賽從公布到總排名的完整操作。圖片和報告寫入 `test-results/browser-smoke/event-templates-browser/`。
