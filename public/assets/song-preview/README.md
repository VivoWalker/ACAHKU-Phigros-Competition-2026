# 本地音乐预览素材（预留）

将已经剪辑好的约 10 秒音频放在此目录，再在控制面板 **Event & library → Song library** 中填写该曲的 **Music preview path**，例如：

```text
assets/song-preview/song-01.mp3
```

支持 MP3、OGG、WAV、M4A。文件名使用英文字母、数字、下划线或短横线；路径为相对于 `public/` 的本地路径。输入框可留空，稍后再补素材；文件不存在也可以先保存路径。

当前版本仅保存素材路径，尚未启用音频加载、试听或自动播放。未来播放器可读取曲目对象的可选 `previewAudio` 字段；空值表示未配置。约 10 秒是素材剪辑建议，当前不会校验或裁剪音频时长。总决赛封存的 MC 曲目必须保持隐藏，在正式揭晓前不得请求其音频。

曲绘放在 `public/assets/song/`，在同一个表单填写 **Local artwork path**，例如 `assets/song/song-01.webp`。请在抽选曲目之前保存素材路径；已经抽出的候选和比赛选曲保留抽取时的素材快照。也可以在相同路径替换文件，再刷新浏览器源。
