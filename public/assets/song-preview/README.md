# 本地音乐预览素材

已从主办方提供的五个 7z 分卷导入 **48 首真实歌曲预览，对应全部 50 个谱面**，每段 10–12 秒（MP3 编码补齐后仍小于 15 秒）。同曲 IN / AT 共用音频。旧歌单中额外的 `What do you want more than a Happy ending?` 未纳入当前曲库。Grand Final 公布曲目页面依次播放 Desultory Signals 和 Petrichor。

[preview-map.csv](preview-map.csv) 记录曲名、对应谱面、原文件名、截取起止时间及素材路径；[manifest.json](manifest.json) 保存时长、哈希和选段依据。28 首以社区导出的游戏预览时间窗为参考，20 首使用段落、起音、低频和波形分析后选取。游戏预览不一定是唯一的高潮，这些选段也未经过听觉试听；每项均记录具体方法。Re：End of a Dream 的原预览只有 9.34 秒，因此增加 0.66 秒非静音前导，保留原结束点。

将剪辑好的 **10–15 秒**音频放在此目录，再在控制面板 **Event & library → Song library** 中填写该曲的 **Music preview path**，例如：

```text
assets/song-preview/song-01.mp3
```

支持 MP3、OGG、WAV、M4A。文件名使用英文字母、数字、下划线或短横线；路径为相对于 `public/` 的本地路径。输入框可留空，稍后再补素材；文件不存在也可以先保存路径。

普通双淘汰赛的 **Song selection** 页面会按以下流程播放：

- 抽出六首候选时不请求、不播放音乐。
- P1 禁曲后淡入播放该首被禁歌曲；结尾淡出，再循环播放。P2 禁曲后先淡出当前音乐，再播放 P2 被禁歌曲。
- 抽出两首正式曲目后，先淡出禁曲音乐，再依次播放第一首和第二首。曲绘、曲名同步切换；第二首结束后停止，保留第二首曲绘。
- 重新抽候选、退出选曲画面、进入加赛或结束比赛会停止预览。普通分数及状态更新不会重新开始播放。

固定两首总决赛使用独立的公布流程：第一首 Desultory Signals（IN17）→ 第二首 Petrichor（AT17），每首只播放一遍，结束后停止；期间不播放菜单 BGM。主控可提前公布第二首或重新播放。该流程使用两段固定的 **12.042449 秒**时间窗，以保证曲绘、声音与红色侵入阶段同步；更换这两首的预览素材时请保持相同时间窗。退出公布页面会淡出预览，刷新或重连按保存的时间点恢复，已播完的片段不会自动重播。

主控的内嵌直播预览保持静音。OBS 使用一个承担声音的 `overlay/live.html` 浏览器源；需要画面但不需要声音的额外浏览器源，在网址加 `?audio=0`（已有查询参数则加 `&audio=0`），避免重复出声。OBS 浏览器源启用 **Control audio via OBS** 后，可在混音器调整音量。普通浏览器若拦截自动播放，点击页面的 **Enable broadcast audio / 啟用直播音訊**；OBS 可通过“交互”操作该按钮。其他页面的界面 BGM 与这里的选曲预览分开管理，进入选曲页面会停止 BGM。

`manifest.json` 将随包素材映射到多个谱面 ID：`tracks` 每项含 `songIds`、`output`（本地路径）和 `duration`（实际秒数）。它也适用于已保存且没有 `previewAudio` 字段的候选曲目，不必重置比赛。曲目自身显式填写的 `previewAudio` 优先；显式空值表示关闭该曲预览。控制面板在旧曲库缺少该字段时显示内置路径，修改其他资料不会顺便关闭音频；手动更换成其他片段时，播放器读取新文件自己的时长。

完整源音乐和压缩包不要放入 `public/` 或提交到仓库。使用 `scripts/prepare-song-previews.py` 生成裁切计划，核对每首歌的时间点后再导出；具体命令见脚本帮助及 [准备说明](../../../docs/song-preview-preparation.md)。自动分析的高能量段不能视为网上确认的高潮位置，推荐在正式比赛前试听确认。

曲绘放在 `public/assets/song/`，在同一个表单填写 **Local artwork path**，例如 `assets/song/song-01.webp`。手动编辑的素材路径仍保留抽取时快照，请在抽候选之前填写；也可在已有路径替换文件后刷新浏览器源。导入清单后请刷新 OBS 浏览器源。
