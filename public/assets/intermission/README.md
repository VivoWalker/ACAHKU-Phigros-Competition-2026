The supplied Arcaea competition trailer is bundled as `arcaea-trailer.mp4` and
automatically selected when no replacement is configured. Open the main
control panel’s **Arcaea 預告** tab and choose **播放預告** to broadcast it.
Entering **休息時間** never starts the trailer automatically.

The panel also supports replacement MP4/WebM uploads up to 250 MiB. Uploaded
clips live under `data/media/intermission/` and are excluded from Git. Save the
uploaded draft before broadcasting a replacement.

See [processing and loudness measurements](../broadcast-videos/README.md).
