Place a locally supplied Arcaea competition trailer here as `arcaea-trailer.mp4`
or another MP4/WebM filename, then save its `assets/intermission/...` path in the
main control panel's **Arcaea 預告** tab.

The panel also supports direct uploads up to 250 MiB. Uploaded clips live under
`data/media/intermission/` and are excluded from Git. The upload fills a draft;
save the settings before broadcasting. No trailer is bundled by default.
