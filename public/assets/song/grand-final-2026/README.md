# Grand Final jackets

This directory contains the original Phigros jacket images for the fixed Grand Final charts:

| Song | Composer | Competition chart | Local asset |
| --- | --- | --- | --- |
| Desultory Signals | technoplanet | IN 17 | `desultory-signals.png` |
| Petrichor | void (Mournfinale) | AT 17 | `petrichor.png` |

Downloaded from [Rhythm Archive's Phigros jacket collection](https://rhythmarchive.github.io/phigros/jacket/), using the same pinned resource catalog as `../song-list-2026/manifest.json`. `manifest.json` records the original resource IDs, URLs, composers, illustrators, byte counts, dimensions and SHA-256 digests. Both files are unmodified 2048 × 1080 PNG originals; the digests, sizes, image decoding and dimensions were checked after download.

The Grand Final uses these two charts directly, with no draw, ban or pick step. Chart levels in the competition configuration are integer display levels supplied by the organiser; no rounding is applied. The chart configuration is in `public/js/competition-config.js`.

Jacket artwork and music remain the property of their respective creators and rights holders. Downloading these resources does not grant a new licence.
